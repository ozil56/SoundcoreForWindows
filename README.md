# SoundcoreForWindows

Windows 上的 **soundcore Work / 安克录音豆 D3200** 托盘工具：BLE 麦克风桥接、设备录音下载、本地语音转写与可选 Ollama 纪要。

基于 [tacshi/Soundcore](https://github.com/tacshi/Soundcore) 的 BLE 协议研究，保留 fork 关系与历史。Windows 实现在 `windows-toolkit/`，使用 Python、Bleak 和 Tk；上游 Flutter 项目保留，说明见 [README.upstream.md](README.upstream.md)。这是社区项目，并非 Anker、飞书或 Typeless 官方产品。

## 七个入口（v2.5）

| 托盘菜单 | 功能 |
| --- | --- |
| 连接录音豆 | 虚拟声卡检测、搜索选择、当前状态、断开与重连 |
| 设备录音管理 | 设备文件列表、下载、删除、下载并删除、打开下载目录 |
| 自动转写 | 上次完成时间、未完成数量、预计运行时间、立即处理、打开转写目录 |
| 自助转写 | 选择本地音频、可选通用/专用词库、开始转写、进度与打开结果 |
| 词库管理 | 通用词库、新词审核；按项目维护专用词库 |
| 设置 | 目录、模型、跨天时间段、自动操作、自启动、Ollama |
| 退出 | 结束后台程序 |

自动连接始终开启；“断开”释放当前连接，30 秒后重试，“重连”立即尝试。设备管理操作独占 BLE，关闭面板后恢复常驻连接。

## 下载与开始使用

1. 从 [Releases](https://github.com/ozil56/SoundcoreForWindows/releases) 获取已发布的 Windows x64 ZIP，完整解压，保留 `_internal`。
2. 打开 Windows 蓝牙，唤醒录音豆，释放手机或其他电脑对它的连接。
3. 运行 EXE，从 **连接录音豆** 搜索、选择自己的设备。无需 Windows 系统配对，也不要求解绑飞书。
4. 从 **设置** 配置本地 ASR 运行程序、模型和保存目录；安装说明见 [Windows 开发与模型说明](windows-toolkit/README.md)。

已在 Windows 11 x64 与飞书版 D3200 固件 04.73 上验证协议；不保证所有固件或其他品牌录音器兼容。不会自动访问未选择的同名设备。

## 日常自动处理与自助转写

自动下载在设备连接且停止录音 15 秒后进行，按每日时间段运行，支持跨天。下载完整并重新校验 SHA256 后，才按设置删除设备原件。重新开始录音时让出连接。

**自动转写** 不展示不断增长的历史列表，只显示数量、上次完成时间和预计运行时间。两个“立即”按钮只为本次跳过时间限制，不改变原设置。电脑需保持开机，程序不会唤醒电脑。

**自助转写** 支持 WAV / MP3 / FLAC / OGG；可使用通用词库、项目词库或临时 TXT，也可完全不用词库。选择文件不会创建任务；点击开始后复制并校验音频，立即排队。旧音频和旧文本不覆盖；重新打开面板可看到最近一批结果。

词库 TXT 为 UTF-8，每行一个词或完整短语。专用词库按项目组织，双击项目进入编辑。删除和停用可恢复，新词审核仍保留在通用词库筛选中。每次转写保存词库快照，后续编辑不改变旧任务。

专用词库页提供 **AI 提取词库指南 / Prompt**：填写项目资料目录、输出目录和会议主题后复制或保存 Prompt，交给 Agent 提取有原文依据的术语、来源核对表及待审核词。添加或导入词条时可选择“先存入待审核”。

## Ollama 标题与纪要

在 **设置** 中启用并测试服务器。默认地址 `http://127.0.0.1:11434`，默认模型 `qwen3:30b-instruct`。启用后会向所配置服务器发送转写文字；默认本机处理。

- 默认不足 **2 分钟**的录音不调用 Ollama，阈值可调整；有效文字不足 80 字也跳过。
- 文件按 `年/月/日` 保存，标题文件例如 `20261111-152313-盐靖施工图审查会.txt`。
- 纪要另存为 `日期-时刻-标题-纪要.txt`，包括标题、主要内容、待办事项、完整正文润色。
- 全文分段处理，保留具体内容；重要事实、数字、责任和期限仍需人工核对。
- 先保存原始转写，Ollama 失败时保留结果并稍后重试，不导致 ASR 成果丢失。原始稿位于日期目录下 `原始转写/`。

## Typeless 麦克风

声音路径：录音豆 → BLE → 本程序 → VB-CABLE → CABLE Output → Typeless。

单独安装 [官方 VB-CABLE](https://vb-audio.com/Cable/)，按安装器要求重启。Typeless 麦克风选择 **CABLE Output** 并关闭“语音输入时静音”；Windows 扬声器保持原设备。按下录音豆侧键，再使用 Typeless 快捷键听写。

桥接固定使用本机 CABLE Input / WASAPI；远程桌面不启用麦克风输出，下载与本地转写不受此限制。程序不处理 Typeless 向编辑器插入文字的兼容性问题。

## v2.5 转写恢复

默认分段最长 60 秒、单段输出上限 4096 tokens，设置可调整为 15–180 秒、512–8192 tokens。检测重复输出，触顶或异常重复时自动细分并重试问题片段。已完成进度保留，不将截断输出当成完整文字。保留 v2.4.2 的外部 ASR Python 隔离修复。

公开交付包不含个人录音、词库、设备身份、模型或虚拟声卡驱动。仅分享原始 ZIP，不分享运行中的个人数据目录。
